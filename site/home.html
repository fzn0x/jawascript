Nulis program nganggo basa Jawa.

Write programs in Javanese. JawaScript keeps the punctuation of JavaScript and TypeScript, swaps the keywords for everyday Javanese words, and compiles to native code through MLIR and LLVM.

Read it like Javanese

Every keyword is an ordinary word of everyday Javanese, so a line of Jawa can be glossed word by word, the way linguists write out a sentence.

The shape of TypeScript

Braces, types after a colon, T[] arrays, template strings, && and i++ all work the way you expect. The words change; the program does not.

Every difference, side by side

interface Wong {
    jeneng: string;
    umur: number;
}

function diwasa(wong: Wong[]): string[] {
    const asil: string[] = [];
    for (const w of wong) {
        if (w.umur >= 18) {
            asil.push(w.jeneng);
        }
    }
    return asil;
}

wujud Wong {
    jeneng: ukara
    umur: wilangan
}

gawe diwasa(wong: Wong[]): ukara[] {
    tetep asil: ukara[] = []
    kanggo (tetep w ing wong) {
        yen (w.umur >= 18) {
            tambah(asil, w.jeneng)
        }
    }
    bali asil
}

Compiled, not interpreted

jawac is a real compiler. A Rust frontend checks types and builds its own MLIR dialect, Jawa passes and LLVM optimize it, and the result links into a native executable with a garbage collector for memory.

Mistakes, explained

The compiler reports every error in a file at once. Type a JavaScript word out of habit and it names the Jawa one; a program that fails while running says why, in Javanese.

$ jawac check salah.jw
error: `let` is not a Jawa keyword
 --> salah.jw:2:5
  |
2 |     let umur = 20
  |     ^^^
  = note: Jawa writes `let` as `ayo`
error: could not compile `salah.jw` because of 1 error

$ jawac run indeks.jw
gagal: indeks 3 ora ana ing larik sing dawane 3

Try it

Build from source on Windows (MSYS2) or Linux with Clang, MLIR, LLVM, Rust and the Boehm collector. The README lists the packages for each.

git clone https://github.com/fzn0x/jawascript.git
cd jawascript
scripts/build.sh
build/bin/jawac run examples/sugeng_rawuh.jw
